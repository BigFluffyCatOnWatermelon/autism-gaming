# Каталоги предметов

Каталоги разделены по категориям:

- `tools.tres` — топоры, кирки и другие инструменты;
- `weapons.tres` — мечи, луки и другое оружие;
- `food.tres` — продукты и готовые блюда;
- `materials.tres` — строительные и ремесленные материалы;
- `ammunition.tres` — стрелы и прочие боеприпасы.

Каждый файл — ресурс `ItemCatalog`. Его массив `items` содержит подресурсы `ItemDefinition`. Все поля предмета находятся в одном месте:

| Поле | Назначение |
|---|---|
| `item_id` | Уникальный ID, используемый инвентарём и кодом |
| `display_name` | Название в интерфейсе |
| `description` | Описание в подсказке и Debug Inspector |
| `category` | Категория предмета |
| `stack_limit` | Максимум предметов в одной стопке |
| `icon` | Текстура предмета |
| `properties` | Дополнительные свойства и значения для описания/эффектов |
| `combat_stats` | Параметры боевой системы: урон, скорость, дальность и т. д. |

Инструменты и оружие всегда принудительно получают `stack_limit = 1`: каждый экземпляр — отдельный объект в мире и отдельная ячейка инвентаря. Для материалов, еды и боеприпасов лимит стопки задаётся в ресурсе.

## Как добавить предмет

1. Открой соответствующий файл `.tres` в Godot или текстовом редакторе.
2. Добавь внешний ресурс иконки в секцию `[ext_resource]`.
3. Создай новый `[sub_resource type="Resource"]`, назначь скрипт `item_definition.gd` и заполни поля предмета.
4. Добавь `SubResource("ID_ресурса")` в массив `items` в конце файла.
5. Укажи уникальный `item_id`. Он должен совпадать с ID, который использует игровой код.

Загрузчик `item_catalog_service.gd` автоматически собирает каталоги в общие таблицы предметов и боевых характеристик. Иконки, подписи инвентаря, меню Debug Spawn и игровые атаки читают данные из этих ресурсов.

Таблицы добычи, рецептов, периодического производства и расписаний пока остаются настройками соответствующих механик (legacy JSON). Их runtime-чтение нормализуется общим ObjectGameplayTableService; это не дублирует определения предметов и не меняет item_id. Перенос этих таблиц в отдельные типизированные ресурсы с редактором и автоматической проверкой ссылок запланирован отдельно.

## Кнопка «База»

В Debug Inspector выбери конкретный предмет в мире и измени нужную характеристику. Кнопка «База» рядом с редактируемым полем сохраняет это значение в исходный файл категории через `ResourceSaver.save()`. Например, урон меча обновится в `weapons.tres`, а лимит стопки хлеба — в `food.tres`.

Кнопка видна только в Debug Inspector, поэтому для редактирования нужно включить режим отладки. После сохранения каталог загружается при каждом запуске игры независимо от того, включён ли Debug Inspector.

Сохранение исходного `.tres` рассчитано на запуск проекта из доступной для записи папки с исходниками. В экспортированной сборке ресурсы внутри PCK обычно недоступны для записи — там нужно менять файлы проекта и собирать игру заново.

## Еда

Каталог содержит иконки и определения еды из CozyVillageFarm. Сейчас еду можно создать, подобрать и хранить в инвентаре. Механика употребления и эффекты восстановления здоровья/выносливости ещё не подключены. Для будущих эффектов используй словарь `properties`, например `restore_health` или `restore_stamina`; числовые свойства еды доступны для редактирования в Debug Inspector.
