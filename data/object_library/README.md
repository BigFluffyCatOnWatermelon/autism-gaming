# Библиотека игровых объектов

Библиотека хранит описания объектов отдельно от их сцен и экземпляров в игровом мире.

## Формат хранения

- objects/<object_id>.tres — ObjectDefinition, метаданные, пользовательские свойства и список компонентов.
- templates/<template_id>.tres — определения шаблонов.
- scenes/<object_id>.tscn — PackedScene, визуальная и физическая структура объекта.
- object_id — постоянный ID. Название объекта можно менять; ID после начала использования в сохранениях менять нельзя.

Категория, теги и описание — данные каталога, а не имя папки. Поэтому пользовательские категории не требуют изменения схемы или кода.

## Создание из шаблона

Шаблон — отдельное определение ObjectDefinition с флагом is_template. При создании копии переносятся метаданные и пользовательские свойства. Если у шаблона есть сцена, создаётся независимая копия PackedScene с новым ID; сцена шаблона не редактируется.

Встроенные заготовки: пустой Node2D, StaticBody2D, Area2D и RigidBody2D. Пользовательский шаблон можно сохранить флажком «Сохранить как шаблон» при создании нового определения.

## Совместимость

Каждый ObjectDefinition содержит schema_version. Перед сохранением проверяются обязательные поля и уникальность ID свойств. При перезаписи существующего файла последняя версия сохраняется как резервная копия .bak. Файлы .bak не сканируются библиотекой.

Неизвестные поля нельзя удалять при обновлении схемы. Миграции должны быть отдельными явными шагами с резервной копией и проверкой результата. В версии 0.1.0 автоматических миграций нет.

## Экземпляры

Определение — общий шаблон. Экземпляр — созданный из него узел в сцене или во время игры. Изменения экземпляра не должны автоматически перезаписывать определение; будущая система overrides будет хранить отличающиеся значения отдельно.
