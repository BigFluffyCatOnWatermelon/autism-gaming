## Подтверждённые требования пользователя

- Игра будет 2D.
- Пользователь хочет разрабатывать и запускать её через браузер.
- Код и изменения будут делаться вместе с ChatGPT.
- Нужно учитывать ограничения бесплатной версии ChatGPT и не тратить контекст на лишние переписывания.
- В новых чатах контекст должен восстанавливаться из файлов репозитория.

## Зафиксированный технологический стек

- Phaser **4.2.1** — 2D-движок.
- JavaScript ES modules — основной язык.
- Vite **8.3.5** — dev-сервер и сборка.
- StackBlitz WebContainers — браузерная среда.
- GitHub — хранение кода и коммитов.

Vite требует Node.js 20.19+ или 22.12+. В StackBlitz среда Node.js предоставляется WebContainers, локально устанавливать Node.js не нужно.

## Как запустить

Открыть ссылку:

https://stackblitz.com/github/BigFluffyCatOnWatermelon/autism-gaming

Дождаться импорта и установки зависимостей. Ожидаемый сценарий — автоматический запуск `npm run dev` и появление Preview.

Команды:
- `npm run dev` — разработка.
- `npm run build` — production-сборка.
- `npm run preview` — просмотр сборки.

## Текущий технический прототип

Добавлена тестовая сцена `PlaygroundScene`, которая не задаёт жанр или будущий визуальный стиль игры.

Реализовано в стартовом коде:
- создание экземпляра Phaser;
- адаптивный масштаб игрового окна 960×540;
- отрисовка тестового фона и сетки;
- тестовый светящийся круг;
- перемещение по WASD или стрелкам;
- возврат объекта в центр по R;
- оформление браузерной страницы.

Сцена нужна только для проверки движка, клавиатуры, отрисовки и Preview. Её можно будет удалить или заменить после утверждения концепции.
