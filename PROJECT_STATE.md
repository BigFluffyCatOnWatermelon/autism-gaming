# Состояние проекта

**Дата обновления:** 2026-11-02  
**Этап:** базовая пиксельная песочница  
**Статус:** код и ассеты сохранены в GitHub; автоматическая проверка сборки включена. Последняя версия требует проверки пользователем в StackBlitz.

## Репозиторий и среда

- GitHub: https://github.com/BigFluffyCatOnWatermelon/autism-gaming
- Основная ветка: `main`
- StackBlitz: https://stackblitz.com/github/BigFluffyCatOnWatermelon/autism-gaming
- Среда: браузер / StackBlitz WebContainers.
- Установка программ на компьютер пользователя не требуется.
- GitHub — основной источник кода.

## Подтверждённые требования пользователя

- 2D-игра с пиксельной графикой.
- Разработка и запуск через браузер.
- Бесплатный рабочий процесс с экономным использованием контекста ChatGPT.
- Часто изменяемые параметры вынесены в отдельный, документированный конфиг.
- Код нужно подробно комментировать.
- F3 должен позволять выбирать объекты и менять их параметры на лету.
- Логи должны фиксировать игровые и отладочные события.
- В новых чатах контекст должен восстанавливаться из файлов репозитория.

## Технологический стек

- Phaser **4.2.1** — 2D-движок.
- JavaScript ES modules.
- Vite **8.3.5**.
- StackBlitz WebContainers.
- GitHub Actions: `npm test` и `npm run build`.
- GitHub — исходники и история коммитов.

## Что реализовано в коде

### Мир
- Пустая карта 3600×3600.
- Бесшовно повторяемая трава с декоративными пиксельными деталями.
- Мир имеет редактируемые границы.
- Травяной слой ограничен размером экрана и прокручивается с камерой, чтобы не создавать огромную текстуру.

### Персонаж
- Оригинальный пиксельный spritesheet 32×40.
- Четыре направления, четыре кадра на направление.
- Анимации ходьбы и idle.
- Отдельная тень, подсветка и сортировка по Y.
- Ходьба, бег, приседание и перекат.
- Расход и восстановление выносливости.

### Камера
- Плавное следование за персонажем.
- Отдельный зум для обычного движения, бега и приседания.
- Тряска при боевых действиях и перекате.
- Базовые значения вынесены в конфигурацию.

### Оружие и урон
- 9 ячеек быстрого доступа.
- Меч: ЛКМ — размашистый режущий удар по сектору; ПКМ — колющий тычок по узкому сегменту. Разные урон, дальность, стоимость выносливости и перезарядка.
- Кирка: колющий урон, бонус по камню.
- Топор: режущий урон, бонус по дереву и материалу природы (задел под энтов).
- Лук и стрелы: выстрел в направлении курсора, расход стрел.
- Общая система рассчитывает тип урона, силу персонажа и уязвимость материала.
- Есть общая регистрация боевых целей через `WorldScene.registerCombatTarget()`.

### Интерфейс и инвентарь
- HUD здоровья и выносливости.
- Панель из 9 слотов.
- Инвентарь открывается на B.
- Слоты брони: голова, тело, ноги, обувь.
- 12 открытых слотов рюкзака + 12 закрытых ячеек как задел для будущих покупок.
- Отображение характеристик персонажа, защиты и выбранного предмета.
- Настройки: тряска, эффекты камеры, FPS, громкость-заглушка; сохраняются в localStorage.

### Разработческие инструменты
- F3 — режим разработчика.
- Наведение и клик по зарегистрированному объекту выбирают его в инспекторе.
- Список целей отладчика динамический: `WorldScene.registerDebugTarget()`.
- Параметры общих систем берутся из `src/config/gameConfig.js` и `DEBUG_FIELDS`.
- Можно добавлять объектные поля через `fields` с `getValue` / `setValue`.
- F2 и кнопка «Логи» открывают журнал; события также выводятся в консоль.

## Структура

- `src/main.js` — инициализация Phaser.
- `src/config/gameConfig.js` — все важные числовые настройки, категории, пояснения и F3-поля.
- `src/game/WorldScene.js` — мир, персонаж, камера, управление, эффекты и атаки.
- `src/game/CombatSystem.js` — типы урона, сопротивления и геометрия попаданий.
- `src/ui/GameUI.js` — HUD, инвентарь, настройки, инспектор и лог.
- `src/style.css` — оформление.
- `public/assets/grass.png` — тайл травы.
- `public/assets/player.png` — спрайт-лист персонажа.
- `public/assets/items.png` — пиксельные иконки предметов.
- `public/assets/shadow.png` — тень.
- `public/assets/ASSET_SOURCES.md` — происхождение и лицензии графики.
- `tests/combat.test.js` — автоматические проверки математики боя.
- `.github/workflows/build.yml` — CI тесты и production-сборка.

## Что ещё не реализовано

- Деревья, камни, кусты, враги, NPC и добыча ресурсов.
- Реальное применение урона к существам и ресурсам в игровом мире (для них уже есть общая API-регистрация).
- Экипируемые предметы брони и влияние предметов на характеристики.
- Перетаскивание предметов между ячейками.
- Расширение рюкзака через магазин и валюту.
- Сохранение персонажа, инвентаря и мира между сессиями.
- Звуки, музыка и финальный игровой цикл.
- Дополнительные анимации атаки самого персонажа: сейчас есть анимированные эффекты оружия и базовые направленные walk/idle.

## Управление

| Клавиша / ввод | Действие |
|---|---|
| WASD / стрелки | Движение |
| Shift | Бег |
| C | Присесть |
| Space | Перекат |
| B | Инвентарь |
| F3 | Отладчик |
| F2 | Журнал |
| 1–9 | Выбор слота |
| ЛКМ | Основная атака / выстрел |
| ПКМ | Вторичная атака меча |
| Мышь | Направление прицеливания |
| Esc | Закрыть открытое окно |

## Известные ограничения / проверки

- Файлы сохранены на GitHub.
- GitHub Actions выполняет `npm test` и `npm run build`.
- Последние запуски CI нужно сверять в Actions: https://github.com/BigFluffyCatOnWatermelon/autism-gaming/actions
- Последняя версия требует визуальной проверки пользователем в StackBlitz.
- В пустом мире атаки показывают следы и эффекты, но не могут наносить урон, пока не добавлены цели.
- Слоты брони — пока UI-заготовка, экипируемой брони ещё нет.

## Правила для новых чатов

1. Прочитать README, AGENTS, PROJECT_STATE, TASKS и последние записи CHANGELOG.
2. Проверить реальные файлы и актуальные SHA/ветку.
3. Не повторять реализованное и не переписывать рабочие системы без причины.
4. Частые настройки добавлять в gameConfig.js с объяснениями и DEBUG_FIELDS.
5. Новые объекты подключать к общей регистрации F3 и боевой системе.
6. После изменений выполнять тесты/сборку и обновлять документы.
7. Всегда честно указывать, что проверено в CI, а что проверено только пользователем в браузере.
