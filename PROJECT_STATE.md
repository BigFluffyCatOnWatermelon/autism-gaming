## Репозиторий

- Основная ветка: `main`
- Среда разработки: браузер.

## Подтверждённые требования пользователя

- Игра будет 2D.
- Пользователь хочет разрабатывать и запускать её через браузер.
- Код и изменения будут делаться вместе с ChatGPT.
- Нужно учитывать ограничения бесплатной версии ChatGPT и не тратить контекст на лишние переписывания.
- В новых чатах контекст должен восстанавливаться из файлов репозитория.

## Технологии

Предварительно рассматривается:

- Phaser 3 — 2D-движок.
- JavaScript — основной язык.
- Vite — запуск и сборка браузерного проекта.
- StackBlitz — редактирование и запуск в браузере.

**Важно:** стек пока не утверждён окончательно и ещё не подключён. Не описывать его как уже реализованный. Зафиксировать окончательный выбор перед созданием файлов приложения.

1. Сначала прочитать `README.md`, этот файл, `TASKS.md` и последние записи `CHANGELOG.md`.
2. Проверить реальные файлы и текущую ветку репозитория.
3. Не повторять уже выполненную работу.
4. Перед существенными архитектурными решениями сверяться с подтверждёнными требованиями.
5. Не менять несвязанные части и не переписывать рабочий код без необходимости.
6. После каждой завершённой задачи обновлять состояние, задачи и журнал изменений.
7. Честно указывать, что действительно было запущено и проверено.
