# Integration request — physics

## Что реализовано локально

Все десять механик содержат собственные методы, настройки, валидацию и сигналы:

- `has_collision`: находит вложенные `CollisionShape2D` / `CollisionPolygon2D` и включает/отключает их через `set_deferred`.
- `blocks_movement`: включает/отключает выбранный бит `collision_layer`.
- `can_be_pushed`, `can_be_pulled`: прикладывают импульс к `RigidBody2D` либо меняют скорость `CharacterBody2D`.
- `has_mass`, `affected_by_gravity`: задают `mass` и `gravity_scale` у `RigidBody2D`.
- `can_bounce`, `can_slide`, `has_physics_material`: создают независимую копию `PhysicsMaterial` и меняют её свойства.
- `can_roll`: задаёт угловую скорость `RigidBody2D`.

## Контракт, который должен обеспечить Object Builder

1. Создавать/сохранять целевые физические узлы и формы коллизии отдельно от механик.
2. Вызывать `bind_target(Node)` после создания/восстановления объекта и до команд механики.
3. Передавать `CollisionObject2D` для изменения слоя; `StaticBody2D` / `RigidBody2D` для PhysicsMaterial; `RigidBody2D` для массы, гравитации и вращения.
4. Для `CharacterBody2D` вызывать push/pull из корректной части игрового цикла. Данный компонент добавляет величину к `velocity`; он не вызывает `move_and_slide()`.
5. Согласовывать `collision_layer` объекта с `collision_mask` тех тел, которые должны его учитывать. Само включение битового слоя не заставляет произвольные тела сталкиваться с ним.
6. Сохранять пользовательские значения свойств в определении объекта. Компоненты применяют их к узлам в runtime, но не меняют структуру сцены.

## Ограничения и важные детали

- `has_collision` работает только с уже существующими `CollisionShape2D` и `CollisionPolygon2D`. При отсутствии форм сообщает ошибку. Оно не генерирует форму автоматически.
- Отключение форм коллизии выполняется отложенно для безопасности физического сервера Godot; читать итоговое состояние в том же кадре нельзя.
- Push/pull для `CharacterBody2D` — изменение скорости, а не физически точный импульс с учётом массы. Для естественной физической симуляции используйте `RigidBody2D`.
- `can_be_pulled` принимает узел-источник и ограничивает дистанцию; препятствия на линии притяжения не проверяются.
- Масса, gravity scale, вращение и PhysicsMaterial в этой реализации адресованы `RigidBody2D` для массы, gravity scale и вращения; `StaticBody2D` / `RigidBody2D` для PhysicsMaterial. Другим типам узлов компонент вернёт понятную ошибку.
- Компоненты не создают дополнительные коллайдеры, не меняют слои других объектов и не управляют глобальными настройками физики.
- `can_slide` меняет friction PhysicsMaterial. Скорость скольжения также зависит от типа тела, физического контакта, damp и других параметров проекта.

## Интеграционные smoke-тесты

`tests/smoke.gd` создаёт реальные узлы Godot и проверяет изменение collision shapes, collision layer, velocity, mass, gravity, angular velocity и PhysicsMaterial. Тест не выполнялся в среде генерации, потому что исполняемый файл Godot отсутствует.
