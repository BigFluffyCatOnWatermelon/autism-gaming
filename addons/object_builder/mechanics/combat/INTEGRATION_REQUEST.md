# Интеграция: бой

Содержит 10 механик каталога. Атака и получение урона используют существующие runtime-компоненты; остальные восемь реализованы в combat_rule.gd.

Публичные методы: block_damage, resolve_parry, begin_dodge, set_aim_direction, get_charge_multiplier, roll_critical_hit, register_combo_hit, advance_combo, set_target, get_target и clear_target.

Важно: сами по себе правила не меняют игровой pipeline. Runtime должен вызывать их в корректном порядке и применять возвращённый результат. Уклонение должно управлять временной неуязвимостью; парирование — окном ввода; блок — остаточным уроном. До интеграции и тестирования не показывать статус «Работает».
