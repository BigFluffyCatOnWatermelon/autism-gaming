# Реализованные модули механик

## characteristics
Девять характеристик: выносливость, мана, энергия, голод, жажда, температура, ограничение веса, настроение и репутация. Общий компонент предоставляет ограниченное числовое состояние и операции изменения.

## combat
Десять механик боя. Атака и получение урона используют существующие runtime-компоненты. Блок, парирование, уклонение, прицеливание, заряд, критический удар, комбо и выбор цели имеют отдельные публичные операции.

## Статус
Скрипты и smoke-сценарии добавлены. Возможности не считаются доступными в простом UI до регистрации в реестре, подключения сериализации/зависимостей и успешного прогона тестов Godot 4.7.2.
