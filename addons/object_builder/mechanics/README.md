# Каталоги автономных механик

Каждая новая механика размещается в собственной папке:

~~~text
addons/object_builder/mechanics/<module_id>/
~~~

Папка считается загружаемым пакетом, если в ней есть module.cfg. Загрузчик обходит непосредственные подпапки этого каталога, сортирует их по имени и регистрирует каждую через API v1.

Не клади сюда шаблоны без module.cfg: они не будут загружены.

Перед созданием пакета прочитай в корне проекта:
- MECHANIC_MODULE_STANDARD.md;
- MECHANIC_MODULE_CHAT_PROMPT.md;
- MECHANIC_MODULE_REQUEST_TEMPLATE.md.

Основные правила:
- одна пользовательская механика — одна папка;
- все её runtime-компоненты, определения, ресурсы, README и тесты остаются внутри папки;
- для регистрации используются build_component_definitions() и build_capability_definitions();
- центральные каталоги, ObjectFactory и UI не правятся для каждого пакета отдельно;
- API v1 не гарантирует порядок загрузки и зависимости между сторонними модулями.

Загрузка происходит автоматически из редакторского плагина и из ObjectFactory перед созданием runtime-объекта. GDScript-модуль — доверенный код проекта, а не песочница.

Существующие встроенные механики пока находятся в центральных каталогах. Их перенос в этот формат выполняется отдельно, по одной механике и с сохранением прежних ID.
