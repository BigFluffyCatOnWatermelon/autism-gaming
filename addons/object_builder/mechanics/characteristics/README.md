# Характеристики — runtime-модуль

Включает девять механик: выносливость, ману, энергию, голод, жажду, температуру, ограничение веса, настроение и репутацию. Здоровье остаётся в отдельном существующем модуле.

## Общий API
- `get_value()`, `get_maximum()`, `get_ratio()`
- `set_value(value)`, `add_value(amount)`, `spend_value(amount)`
- `tick(delta, rate_per_second)` для изменения во времени

Значение ограничивается минимумом и максимумом. Отрицательный rate уменьшает значение, положительный — увеличивает. Runtime должен сам определять периодичность вызова tick.
