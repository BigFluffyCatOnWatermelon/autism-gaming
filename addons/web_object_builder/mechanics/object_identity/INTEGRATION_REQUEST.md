# Требования к интеграции: object_identity

Пакет содержит десять независимых `ObjectComponent`-компонентов. Внутреннее состояние доступно через `export_runtime_state()` и `import_runtime_state()`.

Перед переводом карточек в полностью доступный runtime-режим необходимо подтвердить следующие контракты ядра:

1. Ядро вызывает `_on_configured()` после загрузки настроек компонента.
2. Ядро сохраняет словарь `export_runtime_state()` в состоянии экземпляра объекта и передаёт его обратно через `import_runtime_state()` при восстановлении.
3. Изменение runtime-настроек не должно автоматически перезаписывать исходное определение/шаблон объекта.
4. `ResourceUID.create_id()` создаёт UID; ядро отвечает за его сохранение вместе с экземпляром. Без сохранения ID будет новым после повторной конфигурации.

Пакет не вызывает методы `ObjectFactory`, реестров, каталогов или UI и не зависит от других пакетов механик.
