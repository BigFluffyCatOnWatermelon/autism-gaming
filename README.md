# Autism Gaming

Двухмерная пиксельная игра. Основная версия разрабатывается и запускается в Godot 4.7.2 Standard.

## Репозиторий
- GitHub: https://github.com/BigFluffyCatOnWatermelon/autism-gaming
- Ветка main — Godot.
- Ветка phaser-archive — сохранённый Phaser-прототип.

## Требования
- Godot 4.7.2 Standard для Windows x86_64 (не .NET / Mono).
- Git for Windows для получения обновлений.
- Node.js, npm и сторонние игровые библиотеки не требуются.

Официальная загрузка Godot: https://godotengine.org/download/archive/4.7.2-stable/

Распакуй архив Godot в постоянную папку и запусти Godot_v4.7.2-stable_win64.exe. Установка в Windows не нужна.

## Первый запуск
1. Один раз клонируй репозиторий, если ещё не делал этого:
   git clone https://github.com/BigFluffyCatOnWatermelon/autism-gaming.git
2. Запусти Godot Project Manager.
3. Нажми Import и выбери файл project.godot из локальной папки репозитория.
4. Нажми Import & Edit.
5. Запусти игру клавишей F5 (главная сцена) или F6 (текущая сцена).

Главная сцена: scenes/world.tscn.

## Редактирование мира и GUI в Godot
- Открой scenes/world.tscn: в дереве сцены находятся Player, WorldObjects и отдельные узлы Tree_001…Tree_100 и Rock_001…Rock_075. В 2D-окне отображаются сам персонаж и ресурсы; можно выбирать и передвигать объекты мышью.
- Открой scenes/game_ui.tscn, чтобы редактировать HUD, хотбар, инвентарь и окна настроек/отладки/журнала. Скрипт интерфейса имеет режим @tool и создаёт предварительный вид прямо в редакторе. При первом редактировании сохрани сцену (Ctrl+S): созданные элементы получат владельца этой сцены и останутся редактируемыми при следующих открытиях.
- Повторно не удаляй узлы UI, если хочешь сохранить разметку: после сохранения сцена использует существующие контролы, а не создаёт их заново.
- Отдельные сцены Player, Tree и Rock находятся в папке scenes; изменение их внешнего вида или коллизии применяется ко всем экземплярам соответствующего типа.
- Зелёный прямоугольник EditorGround нужен для предпросмотра в редакторе. При запуске игры поверх него создаётся игровая травяная TileMapLayer с текстурой grass.png.

## Получение обновлений
После изменений, отправленных в GitHub, открой Git Bash в папке проекта и выполни git pull. После получения изменений вернись в Godot. Редактор обычно сам замечает изменённые файлы; если нет — перезапусти проект.

После проверки совместимого Git-плагина можно использовать Pull прямо внутри Godot. Git for Windows остаётся надёжным резервным способом.

## Структура Godot-проекта
| Путь | Назначение |
|---|---|
| project.godot | Настройки проекта и главная сцена |
| scenes/world.tscn | Основная сцена со всеми объектами мира |
| scenes/game_ui.tscn | Отдельная редактируемая сцена интерфейса |
| scenes/player.tscn | Игрок, спрайты, удерживаемый предмет, коллизия и камера |
| scenes/tree.tscn | Шаблон дерева и его коллизия |
| scenes/rock.tscn | Шаблон камня и его коллизия |
| scripts/game_config.gd | Централизованные параметры и баланс |
| scripts/world_controller.gd | Создание травы, ввод, атаки и связь систем |
| scripts/player_controller.gd | Движение, анимация, выносливость, перекат и предмет в руке |
| scripts/resource_node.gd | Деревья, камни, здоровье и коллизии |
| scripts/combat_system.gd | Расчёт урона и совместимость оружия с ресурсами |
| scripts/game_ui.gd | HUD, инвентарь, хотбар, настройки, отладчик и журнал |
| public/assets/ | Оригинальные PNG-ресурсы, включая атлас предметов |

## Git внутри Godot
Для Godot 4.7 можно проверить Asset Library-плагин Godot Git (автор Markus Steen, версия 0.3.0 на момент подготовки порта). Он поддерживает stage, commit, pull, push и просмотр истории, но опубликован как unstable — сначала проверь его на нашем проекте.
https://store.godotengine.org/asset/markus-steen/godot-git/

Не устанавливай старый godot-git-plugin v3.2.1 вслепую: опубликованная совместимость ограничена API Godot 4.2–4.4. Если новый плагин окажется нестабильным, используй Git Bash: git pull.

## Проверки
GitHub Actions автоматически запускает headless-проверку проекта Godot при push в main и при pull request. Проверка импортирует ресурсы, загружает редактор и кратко запускает главную сцену.
Локальное визуальное редактирование GUI и проверка управления должны быть подтверждены в настольном Godot 4.7.2.

## Графика
