# Autism Gaming

Двухмерная пиксельная игра на Godot 4.7.2 Standard / GDScript.

## Репозиторий
- GitHub: https://github.com/BigFluffyCatOnWatermelon/autism-gaming
- **main** — основная ветка Godot.
- **phaser-archive** — резервная ветка старого Phaser-прототипа.

## Требования и запуск
- Godot 4.7.2 Standard для Windows x86_64 (не .NET / Mono).
- Git for Windows для обновлений.
- Node.js и npm не нужны.

Загрузить Godot: https://godotengine.org/download/archive/4.7.2-stable/

Если проект ещё не клонирован, выполни в Git Bash:
    git clone https://github.com/BigFluffyCatOnWatermelon/autism-gaming.git

В Godot Project Manager выбери Import, укажи project.godot и нажми Import & Edit. F5 запускает главную сцену.

## Строго три основные сцены

В scenes/ находятся ровно три .tscn:

| Сцена | Содержимое |
|---|---|
| scenes/world.tscn | Игровой мир, встроенный Player, камера, контроллер и экземпляры UI/Objects |
| scenes/ui.tscn | HUD, хотбар, инвентарь, настройки, журнал и Debug Inspector |
| scenes/objects.tscn | Один образец дерева и один образец камня для ручного редактирования; дополнительные экземпляры создаются при запуске |

world.tscn — главная сцена проекта. В 2D-редакторе видны игрок и два образца ресурсов. В запущенном мире автоматически создаются 100 деревьев и 75 камней; в objects.tscn остаётся по одному образцу каждого типа для редактирования.

Открой ui.tscn отдельно, чтобы просмотреть интерфейс. game_ui.gd создаёт редакторское дерево контролов и назначает владельца узлам сцены; после первого открытия сохрани сцену сочетанием Ctrl+S. При необходимости можно двигать и изменять элементы как обычные Control-ноды.

## Управление

| Действие | Клавиша |
|---|---|
| Движение | WASD / стрелки |
| Бег | Shift |
| Присесть | Ctrl |
| Перекат | Space |
| Выбрать слот хотбара | 1–9 |
| Инвентарь | B |
| Закрыть окно / настройки | Esc |
| Debug Inspector | F3 или Настройки → Режим выделения объектов |
| Журнал | F2 |
| Атака / выстрел из лука | ЛКМ (удержание повторяет атаку по кулдауну) |
| Альтернативная атака / выстрел из лука | ПКМ (удержание повторяет атаку по кулдауну) |
| Выбросить предмет из выбранного слота | Q |
| Направление атаки | Курсор мыши |

F3 включает отладочный режим: выбор игрока/ресурса/дропа кликом или через список, фильтр по типу, панель редактирования параметров, клонирование и подтверждаемое удаление объектов. Временные читы бесконечной выносливости и неуязвимости выключены по умолчанию и действуют только в текущей сессии.

Инвентарь: иконки оружия и ресурсов, перетаскивание между хотбаром и рюкзаком, объединение стеков и обмен предметов. Предмет можно выбросить клавишей Q или перетянуть из слота на свободную область игрового мира.

## Основные скрипты

| Файл | Назначение |
|---|---|
| scripts/game_config.gd | Баланс и параметры по умолчанию |
| scripts/world_controller.gd | Ввод, бой, ресурсы, дропы, инвентарь, подбор и отладчик |
| scripts/player_controller.gd | Движение, выносливость, анимация, перекат и предмет в руке |
| scripts/resource_node.gd | Дерево, пень, камень, здоровье, сопротивления и разрушение |
| scripts/resource_drop.gd | Физическое выпадение, отскок, притяжение и подбор |
| scripts/arrow_projectile.gd | Видимая модель стрелы и состояние застревания в земле |
| scripts/inventory_slot.gd | Перетаскиваемый слот инвентаря |
| scripts/combat_system.gd | Расчёт урона и совместимость оружия |
| scripts/game_ui.gd | HUD, инвентарь, подсказки и Debug Inspector |
| Assets/ | Каталог ассетов по 17 категориям; актуальные пути Godot находятся здесь |
| public/assets/ | Совместимые копии файлов старого Phaser-прототипа |

## Получение обновлений без потери локальных правок

Сначала проверь локальные изменения:
    git status --short

Если список пуст, обнови основную ветку:
    git switch main
    git pull --ff-only origin main

Если есть незакоммиченные изменения, сначала сохрани их отдельным коммитом или во временном stash. Например:
    git stash push -u -m "before gameplay update"
    git switch main
    git pull --ff-only origin main
    git stash pop

При конфликтах после stash pop Git оставит файлы для ручного разрешения; не удаляй свои локальные изменения. После обновления открой project.godot в Godot 4.7.2.

## Проверки
GitHub Actions выполняет импорт ресурсов, проверку GDScript и краткий headless-запуск главной сцены при push в main и при pull request. Headless CI не заменяет визуальную проверку UI, управления и работы мышью в настольном Godot 4.7.2.

## Каталог ассетов

Все актуальные ассеты Godot находятся в `Assets/` и распределены по категориям:
`Environment`, `Resources`, `Buildings`, `Furniture`, `Items`,
`Weapons`, `Tools`, `Creatures`, `NPC`, `Interactive`, `Transport`,
`Decorations`, `Effects`, `Projectiles`, `Traps`, `World_Zones`, `System`.

Каждый инструмент/предмет экипировки имеет отдельный файл изображения. Старый
`public/assets/items.png` оставлен только для совместимости с архивным Phaser-кодом;
Godot использует отдельные изображения из `Assets/Weapons`, `Assets/Tools` и `Assets/Items`.
Подробности и назначение папок описаны в README внутри категорий.
