# Autism Gaming

2D-пиксельная игра на **Godot 4.7.2 Standard / GDScript**.

## Запуск

1. Открой Godot Project Manager.
2. Нажми **Import** и укажи файл `project.godot`.
3. Открой проект и нажми **F5** для запуска главной сцены.

Репозиторий: https://github.com/BigFluffyCatOnWatermelon/autism-gaming

## Сцены

| Сцена | Назначение |
|---|---|
| `scenes/world.tscn` | Главная сцена: ландшафт, игрок, пустой контейнер объектов и UI |
| `scenes/terrain.tscn` | Редактируемая карта с отдельными слоями тайлов |
| `scenes/objects.tscn` | Пустой контейнер `Objects`; объекты добавляются вручную |
| `scenes/ui.tscn` | HUD, хотбар, инвентарь, настройки, журнал и Debug Inspector |

**В начальном мире нет деревьев, камней или других ресурсных объектов.** Контейнер `World/Objects` пуст. Автоматического спавна деревьев и камней при запуске больше нет. Чтобы добавить ресурс, перетащи соответствующую сцену из FileSystem в узел `World/Objects`:

- `scenes/objects/tree.tscn`
- `scenes/objects/rock.tscn`
- `scenes/objects/stump.tscn`
- `scenes/objects/log.tscn`

Размещай их именно внутрь `Objects`, а не рядом с ним в корне `World`.

## Ландшафт в стиле Stardew Valley

Ландшафт построен на обычных **TileMapLayer + TileSet** Godot. Это не нарисованный фоновый прямоугольник и не текстура, создаваемая только при запуске: слои присутствуют в дереве сцены и доступны для редактирования в 2D-редакторе.

Открой `scenes/world.tscn` и разверни `Terrain`. Внутри находятся:

| Слой | Что рисовать |
|---|---|
| `Ground` | Базовая трава, 4 варианта текстуры |
| `Soil` | Почва и земляные пятна |
| `Stone` | Каменная поверхность |
| `Sand` | Песок |
| `Water` | Вода с песчаной береговой кромкой |
| `Paths` | Грунтовые дорожки |
| `Decorations` | Кустики, цветы, трава, камешки и грибы |

Размер клетки — **32×32 пикселя**. Если базовый слой травы пуст, редакторская tool-сцена один раз заполняет область 114×114 клеток разными вариантами травы. После этого клетки можно свободно перекрашивать, удалять и заменять. Чтобы намеренно оставить карту совсем пустой, отключи в Inspector у узла `Terrain` параметр `Initialize Ground If Empty`.

### Как рисовать карту

**Важно для Godot 4.7:** перед рисованием отключи верхний инструмент **Scene Paint Mode** (клавиша `B`). Это отдельный режим расстановки копий целых сцен, не режим TileMap. Вернись в обычный режим **Select** (клавиша `Q` или значок стрелки в главной панели 2D-редактора). Иначе при клике появляется сообщение `No scene selected for painting`.

1. Выбери нужный слой, например `Terrain/Soil`, в дереве сцены.
2. Открой нижнюю панель **TileMap**. Она работает только когда выбран узел `TileMapLayer`.
3. В нижней панели выбери вкладку **Tiles** и щёлкни по конкретной клетке атласа. Для обычной рисующей кисти включи инструмент **Paint** в панели TileMap (не Scene Paint Mode в верхней панели 2D).
4. Для `Ground` и `Decorations` рисуй выбранными тайлами обычной кистью, прямоугольником или заливкой.
5. Для `Soil`, `Stone`, `Sand`, `Water` и `Paths` выбери вкладку **Terrains**, затем terrain нужного слоя и режим соединения **Connect**. Теперь рисуй кистью или заливкой — Godot подберёт края и углы автоматически.
6. Сохрани сцену сочетанием **Ctrl+S**.

Каждое покрытие находится на собственном TileMapLayer. Например, можно оставить траву в `Ground`, нарисовать берег на `Sand`, а внутри него озеро на `Water`. Вода получает песчаную кромку, остальные покрытия — травяной переход. Порядок слоёв можно менять в дереве сцены, если понадобится другой визуальный приоритет.

В `Assets/Environment/terrain_atlas.svg` лежат базовые и автотайловые текстуры. У почвы, камня, песка, воды и дорожки есть полноценный набор из 47 вариантов для стыков и углов. `terrain_details.svg` содержит отдельные декоративные тайлы.

### Редактирование объектов

Ресурсные сцены размещаются вручную под `World/Objects`. Для удобного выравнивания у ресурсных объектов есть параметр привязки к сетке. Дерево состоит из ствола и кроны; после разрушения остаётся пень.

## Управление

| Действие | Клавиша |
|---|---|
| Движение | WASD / стрелки |
| Бег | Shift |
| Присесть | Ctrl |
| Перекат | Space |
| Слоты хотбара | 1–9 |
| Инвентарь | B |
| Настройки / закрыть окно | Esc |
| Debug Inspector | F3 или Настройки → Режим выделения объектов |
| Журнал | F2 |
| Атака / выстрел из лука | ЛКМ |
| Альтернативная атака / выстрел из лука | ПКМ |
| Выбросить выбранный предмет | Q |

F3 включает выбор и редактирование параметров объектов, клонирование, удаление и сброс. Изменения Debug Inspector действуют в текущей сессии и не сохраняются в сцену.

## Основные скрипты

| Файл | Назначение |
|---|---|
| `scripts/world_controller.gd` | Бой, ресурсы, дропы, инвентарь, подбор и отладчик |
| `scripts/terrain_editor.gd` | Однократная начальная заливка травяного слоя в редакторе |
| `scripts/player_controller.gd` | Движение, выносливость, анимация и перекат |
| `scripts/resource_node.gd` | Дерево, пень, камень и разрушение |
| `scripts/resource_drop.gd` | Выпадение предметов, физика и подбор |
| `scripts/game_ui.gd` | HUD, инвентарь и Debug Inspector |
| `Assets/Environment/Tilesets/` | TileSet-ресурсы всех ландшафтных слоёв |

## Проверки

GitHub Actions выполняет импорт ресурсов, разбор GDScript и headless-запуск главной сцены. Эта проверка не заменяет визуальное тестирование в настольном Godot: после получения обновлений проверь кисти TileMap, границы покрытий, движение игрока и размещение объектов.

## Получение обновлений

Перед обновлением проверь локальные изменения:

```bash
git status --short
git switch main
git pull --ff-only origin main
```

Если у тебя есть незакоммиченные правки, сначала сохрани их отдельным коммитом или во временный stash.
