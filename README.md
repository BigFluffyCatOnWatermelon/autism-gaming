# Autism Gaming

2D-пиксельная игра на Godot 4.7.2 Standard / GDScript.

## Запуск
Открой `project.godot` через Godot Project Manager и нажми F5.

## Редактирование мира

Открой `scenes/world.tscn` и разверни `Terrain`.

| Слой | Содержимое |
|---|---|
| `Ground` | Сезонная трава, земля, песок, почва, вода, лёд и дорожки |
| `Farming` | 16 культур по 5 стадий |
| `Fence_Wood` | Деревянный забор, 16 соединений |
| `Fence_Dark` | Тёмный забор, 16 соединений |
| `Fence_White` | Белый забор, 16 соединений |
| `Stone_Wall` | Каменная стена, 16 соединений |
| `Decorations` | Цветы, грибы, кристаллы, мелкий декор |
| `AssetLibraries` | Дополнительные каталоги остальных разделов Cozy Village & Farm |

Размер клетки — 16×16. Сезон меняется параметром `Season` корневого узла `Terrain`.

Отключи Scene Paint Mode (B), выбери TileMapLayer и пользуйся нижней панелью TileMap: Paint, Line, Rectangle, Bucket Fill, Select, Picker. Автопереходы Ground используй через Terrains → Connect. Для каждого вида забора есть свой слой, Terrain-набор Match Sides и 16 вариантов соединения.

## Cozy Village & Farm

Оригинальные PNG лежат в `Assets/CozyVillageFarm/`. Плагин заполняет библиотеки тайлов для природы, зданий, предметов, мебели, фермерства, животных, персонажей, пляжа, инвентаря, UI, эффектов, скал и мостов. Все исходные PNG остаются доступны. Картинки на сетке 16 px становятся многоклеточными AtlasSource; изображения нестандартного размера добавляются целиком, а не пропускаются; sprite sheets и анимации создаются отдельными AnimatedSprite2D-сценами или анимированными Ground tiles.

### Коллизии

- Игрок: physics layer 1, mask 2; препятствия: layer 2, mask 1.
- Вода и глубокая вода блокируют движение; береговые углы блокируют только водную четверть. Лёд и мосты проходимы.
- Четыре типа заборов и каменная стена имеют коллизии стоек и секций во всех 16 вариантах.
- Деревья блокируют у ствола, а не кроной; камни — по основанию.
- Здания — по нижней части основания; пропсы и мебель — по опорной части.
- Цветы, трава, ковры, интерфейс и предметы инвентаря проходимы.

### Размещение объектов

Плагин создаёт сцены в `scenes/environment_assets/`. Размещай их внутри соответствующей группы под `World/Objects`:
`Nature`, `Buildings`, `Props`, `Interiors`, `Animals`, `Characters`, `Beach_Fishing`, `Effects`.
Сцены имеют нижнюю точку привязки, сортировку по Y и подходящие коллизии. Животные/персонажи и полосы эффектов создаются с AnimatedSprite2D.

После добавления новых исходников запусти меню **Project → Tools → Cozy Village & Farm: обновить каталоги и сцены**. Каталоги пополняются только отсутствующими PNG. Существующие AtlasSource и ручные правки TileSet сохраняются, команда обновления не очищает библиотеку. Сцены, уже созданные в `environment_assets`, также не перезаписываются.

## Игровые объекты и управление

В `World/Objects` нет автоматического спавна. Игровые ресурсные узлы добавляются отдельно.

- WASD / стрелки — движение; Shift — бег; Ctrl — присесть; Space — перекат.
- 1–9 — слоты; B — инвентарь; Esc — настройки.
- F3 — Debug Inspector; F2 — журнал; ЛКМ/ПКМ — атака; Q — выбросить предмет.
