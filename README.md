# Autism Gaming

2D-пиксельная игра на **Godot 4.7.2 Standard / GDScript**.

## Запуск

1. Открой Godot Project Manager.
2. Нажми **Import** и укажи файл `project.godot`.
3. Открой проект и нажми **F5**.

## Cozy Village & Farm — редактор карты

Оригинальный набор находится в `Assets/CozyVillageFarm/`. Подключённые ресурсы Godot лежат в `Assets/CozyVillageFarm/Godot/TileSets/`.

Открой `scenes/world.tscn` и разверни `Terrain`:

| Слой | Назначение |
|---|---|
| `Ground` | Трава, земля, песок, вода, лёд, дорожки и их автопереходы |
| `Farming` | 16 культур по 5 стадий роста |
| `Fences` | 4 вида заборов и каменные стены с соединениями |
| `Decorations` | Цветы, грибы, мелкие растения, кристаллы и декор |

Размер клетки — **16×16 пикселей**. Сезон меняется в Inspector у узла `Terrain` через параметр **Season**. Все четыре TileSet используют совместимые ID клеток, поэтому карта сохраняется при смене сезона.

### Кисти, заливка и выделение

Выбери нужный `TileMapLayer` в дереве сцены и открой нижнюю панель **TileMap**. Встроенные инструменты Godot дают кисть, линию, прямоугольник, заливку, выделение/копирование/перемещение клеток и пипетку. Для плавных берегов и переходов открой вкладку **Terrains** слоя `Ground`, выбери тип поверхности и рисуй Connect. Для заборов аналогично используй Terrain вкладку слоя `Fences`.

Перед рисованием отключи верхний инструмент **Scene Paint Mode** (клавиша B) и выбери обычный **Select** (Q/стрелка). Scene Paint Mode расставляет PackedScene, а не тайлы. У выбранного `TileMapLayer` редактируй клетки только в нижней панели TileMap.

### Размещение объектов

Плагин **Cozy Village & Farm Tools** включён в проект. При открытии редактора он создаёт PackedScene для статичных спрайтов из разделов Nature, Buildings, Props и Furniture. Они появляются в `scenes/environment/`; сами PNG остаются в оригинальной папке ассета.

Перетаскивай сцену в нужную группу под `World/Objects`:
- `Nature` — деревья, кусты, цветы, камни;
- `Buildings` — здания;
- `Props` — предметы и уличный декор;
- `Interiors` — мебель.

Точка установки спрайта привязана к нижнему центру, глубина рассчитывается по Y. Сцены можно выбирать, двигать, вращать, масштабировать, дублировать и удалять обычными инструментами 2D-редактора. Это декоративные спрайты; игровые деревья/камни с механикой добычи размещаются сценами из `scenes/objects/`.

Подробности — `Assets/CozyVillageFarm/Godot/TileSets/README.md`.

## Объекты и мир

В `World/Objects` нет автоматического спавна деревьев и камней. Добавляй их вручную. Игровые ресурсные сцены:
- `scenes/objects/tree.tscn`
- `scenes/objects/rock.tscn`
- `scenes/objects/stump.tscn`
- `scenes/objects/log.tscn`

## Управление

| Действие | Клавиша |
|---|---|
| Движение | WASD / стрелки |
| Бег | Shift |
| Присесть | Ctrl |
| Перекат | Space |
| Слоты хотбара | 1–9 |
| Инвентарь | B |
| Настройки / закрыть окно | Esc |
| Debug Inspector | F3 или Настройки → Режим выделения объектов |
| Журнал | F2 |
| Атака / выстрел из лука | ЛКМ |
| Выбросить выбранный предмет | Q |

## Проверки

GitHub Actions выполняет импорт ресурсов, разбор GDScript и headless-запуск главной сцены. Проверка не заменяет визуальное тестирование в настольном Godot.
