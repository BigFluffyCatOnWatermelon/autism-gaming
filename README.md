# Autism Gaming

2D-пиксельная игра на Godot 4.7.2 Standard / GDScript.

## Запуск
Открой `project.godot` через Godot Project Manager и нажми F5.

## Редактирование карты

Открой `scenes/world.tscn`, разверни `Terrain`.

| Слой | Содержимое |
|---|---|
| `Ground` | Сезонная трава, земля, песок, почва, вода, лёд, дорожки и переходы |
| `Farming` | 16 культур по 5 стадий |
| `Fence_Wood` | Деревянный забор |
| `Fence_Dark` | Тёмный забор |
| `Fence_White` | Белый забор |
| `Stone_Wall` | Каменная стена |
| `Decorations` | Мелкий декор |
| `AssetLibraries` | Дополнительные каталоги TileSet из остальных разделов ассета |

Сетка — 16×16. Сезон меняется через параметр `Season` корневого узла `Terrain`.

Для рисования отключи верхний Scene Paint Mode (B), выбери TileMapLayer и открой нижнюю панель TileMap. Доступны Paint, Line, Rectangle, Bucket Fill, Select и Picker. Для автопереходов используй Terrains → Connect. Для заборов выбирай соответствующий слой и режим Match Sides.

## Cozy Village & Farm

Оригинальные PNG находятся в `Assets/CozyVillageFarm/`. Плагин создаёт библиотеки тайлов для природы, зданий, пропсов, интерьеров, фермерства, животных, персонажей, пляжа, предметов, UI, эффектов, скал и мостов. Изображения на сетке 16 px добавляются многоклеточными AtlasSource; анимированные sheets превращаются в AnimatedSprite2D-сцены.

Сцены размещаемых объектов появляются в `scenes/environment_assets/`. У деревьев, камней, построек, пропсов, мебели, животных и персонажей есть физические формы. Деревья блокируют движение у ствола, а не кроной; здания — по основанию. Цветы, трава, ковры и UI не блокируют игрока.

Вода/глубокая вода имеют коллизию TileSet. Четыре вида забора и каменная стена доступны отдельными слоями с 16 вариантами соединений и собственными collision polygons. Мосты проходимы.

После добавления новых PNG запусти **Project → Tools → Cozy Village & Farm: обновить каталоги и сцены**.

## Управление
- WASD / стрелки — движение
- Shift — бег; Ctrl — присесть; Space — перекат
- 1–9 — слоты; B — инвентарь
- Esc — настройки; F3 — Debug Inspector; F2 — журнал
- ЛКМ / ПКМ — атака; Q — выбросить предмет
