# Autism Gaming

2D-пиксельная игра на Godot 4.7.2 Standard / GDScript.

## Запуск
Открой project.godot через Godot Project Manager и нажми F5.

## Редактирование карты
Открой scenes/world.tscn и выбери слои под Terrain.

| Слой | Содержимое |
|---|---|
| Ground | Сезонная трава, земля, песок, почва, вода, лёд и дорожки |
| Farming | 16 культур по 5 стадий |
| Fences | Один TileSet с четырьмя стилями заборов/стен |
| Decorations | Мелкий декор |
| AssetLibraries | Остальные библиотеки ассетов |

У забора один TileSet и четыре независимых Terrain Set: дерево, тёмный, белый и камень. Каждый стиль использует собственный AtlasSource с 16 соединениями. Выбирай нужный Terrain Set в слое Fences, автосоединение — через Terrains → Connect.

Размер клетки — 16×16. Сезон меняется параметром Season корневого узла Terrain. Для рисования отключи Scene Paint Mode (B), выбери TileMapLayer и пользуйся нижней панелью TileMap: Paint, Line, Rectangle, Bucket Fill, Select, Picker.

## Как размещать объекты
Готовые сцены генерируются плагином в res://scenes/environment_assets/. В Godot раскрой эту папку в панели FileSystem. Бери файлы .tscn, не исходные PNG.

Открой scenes/world.tscn, разверни World → Objects. Перетащи сцену из FileSystem в 2D-окно или на соответствующую группу:
- Nature — деревья, кусты, камни, растения;
- Buildings — дома, теплица, сарай, магазины;
- Props — сундуки, бочки, фонари и декор;
- Interiors — мебель;
- Animals — животные;
- Characters — NPC;
- Beach_Fishing — лодки, пляжные объекты и рыбалка;
- Effects — визуальные эффекты.

После добавления выбери объект инструментом Select/Move (Q) и передвинь. Сцены привязаны нижним центром, сортируются по Y и содержат коллизию там, где она нужна. Исходные PNG напрямую не перетаскивай.

### Выбор отдельного спрайта из PNG-листа

1. Выбери экземпляр дерева, включи у него **Editable Children** и открой дочерний `Visual` (Sprite2D).
2. Назначь PNG в свойство **Texture**.
3. Для одинаковых ячеек используй **Hframes / Vframes** и **Frame Coords** (счёт начинается с нуля).
4. Для произвольного фрагмента включи **Region → Enabled** и задай **Region Rect**: X, Y, Width и Height.

Меняй параметры у экземпляра, размещённого на карте: обновление каталога Cozy Village может заново сгенерировать исходные сцены деревьев и камней.

Если environment_assets пустая, проверь Project → Project Settings → Plugins → Cozy Village & Farm Tools → Enable и дождись первого импорта. Плагин создаёт сцены локально; на GitHub хранятся исходники и генератор. Для новых ассетов запусти Project → Tools → Cozy Village & Farm: обновить каталоги и сцены.

## Коллизии
Вода и глубокая вода блокируют движение; береговые углы блокируют водную часть. Лёд и мосты проходимы. Деревья блокируют у ствола, камни — внизу, здания — по основанию, заборы — по соединениям. Цветы, трава и ковры не блокируют игрока.

## Управление
- WASD / стрелки — движение; Shift — бег; Ctrl — присесть; Space — перекат.
- 1–9 — слоты; B — инвентарь; Esc — настройки.
- F3 — Debug Inspector; F2 — журнал; ЛКМ/ПКМ — атака; Q — выбросить предмет.

В Debug Inspector:
- Перетаскивай окно за заголовок; в меню «Окно ⚙» меняются ширина, высота и прозрачность. Положение и размеры сохраняются локально.
- «+ Предмет» открывает список всех зарегистрированных предметов и количество для создания предметов возле курсора.
- При выборе предмета в мире в шапке инспектора появляется кнопка «Сохранить предмет в код»: она записывает все изменённые характеристики в соответствующий `.tres`-каталог. У отдельных редактируемых полей также есть кнопка «В код».
- В меню «Окно ⚙» можно менять ширину, высоту, прозрачность и масштаб интерфейса (50–150%).
- В инвентаре и на панели быстрого доступа показываются одинаковые подсказки с описаниями предметов.
- Масштаб выбранного игрового объекта в инспекторе задаётся в процентах (100% — исходный размер).
- Выброшенные игроком предметы нельзя подобрать в течение 0,9 секунды; их радиус притяжения магнитом уменьшен до 35% от обычного.

## Каталоги предметов

Данные предметов находятся в `data/items/` и разделены по категориям: `tools.tres`, `weapons.tres`, `food.tres`, `materials.tres`, `ammunition.tres`. Это текстовые Godot Resources, поэтому их удобно редактировать в Inspector или обычным текстовым редактором.

Каждый каталог содержит список `ItemDefinition`: ID, название, описание, категория, иконка, размер стопки, дополнительные свойства и боевые характеристики. Боевые характеристики из каталогов инструментов и оружия автоматически передаются в боевую систему. Инструменты и оружие всегда имеют размер стопки 1: несколько штук создаются как несколько отдельных объектов мира.

Кнопка «База» сохраняет выбранную характеристику в исходный .tres-файл категории через ResourceSaver. Режим отладки нужен только для изменения значений — сама игра загружает каталоги при каждом запуске и использует их без включённого Debug Inspector. Файл `food.tres` уже содержит предметы с иконками; эффекты употребления еды ещё не реализованы.

Подробная структура и инструкция добавления предметов: `data/items/README.md`.
