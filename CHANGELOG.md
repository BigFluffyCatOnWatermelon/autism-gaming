# История изменений

## 2026-11-02 — Первый перенос на Godot 4.7.2

- Основной проект переведён с Phaser на Godot 4.7.2 Standard / GDScript.
- Старая Phaser-версия сохранена в ветке phaser-archive.
- Добавлены project.godot, основная сцена и отдельные скрипты игрока, мира, ресурсов, боя, конфигурации и UI.
- Перенесены основные действия игрока, камера, травяной мир, деревья, камни, оружие и интерфейс.
- Добавлена headless-проверка проекта Godot в GitHub Actions.
- Обновлены README и инструкции для следующих чатов.

Проверка: файлы подготовлены в GitHub. Запуск Godot CLI в рабочем контейнере недоступен, поэтому локальный запуск и визуальная проверка на компьютере пользователя ещё требуются. Не считать перенос окончательно проверенным до получения результата из Godot 4.7.2.

Новые записи добавляются сверху.
