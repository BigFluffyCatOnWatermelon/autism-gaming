# Подключение Cozy Village & Farm в Godot

TileSet-ресурсы используют оригинальные PNG пакета и размер клетки **16×16**:

- `cozy_ground_spring.tres`, `cozy_ground_summer.tres`, `cozy_ground_autumn.tres`, `cozy_ground_winter.tres` — единый набор поверхностей и угловых переходов для каждого сезона.
- `cozy_crops.tres` — 16 культур, каждая с пятью стадиями роста.
- `cozy_fences.tres` — деревянный, тёмный, белый забор и каменная стена с 4×4 вариантами соединений.
- `cozy_decorations.tres` — цветы, мелкий декор, грибы и кристаллы.

## Слои сцены Terrain

- **Ground** — единый слой поверхностей. Трава, земля, песок, вспаханная/политая почва, вода, лёд и дорожки находятся в одном TileSet, чтобы угловые переходы могли сопоставляться между соседними клетками.
- **Farming** — культуры. Выбирай нужную культуру и стадию в атласе и рисуй клетку.
- **Fences** — заборы и каменные стены.
- **Decorations** — мелкая растительность и декор.

Сезон меняется в Inspector у корневого узла `Terrain`, свойство **Season**. ID источников и координаты в сезонных TileSet одинаковы, поэтому размещённые клетки не сбрасываются при смене сезона.

## Встроенные инструменты TileMapLayer

Выбирай конкретный слой в Scene Tree, затем редактируй его в нижней панели **TileMap**. Доступны штатные инструменты Godot:

- Paint — кисть;
- Line — линия;
- Rectangle — прямоугольник;
- Bucket Fill — заливка;
- Select — выделение, копирование и перемещение клеток;
- Picker — пипетка для выбора уже размещённого тайла.

Для автотайлов на слое **Ground** открой вкладку **Terrains**, выбери тип поверхности и рисуй инструментом Connect. Набор переходов использует режим **Match Corners**. Он построен по угловой схеме из `01_Terrain/Autotiles/_AUTOTILE_LAYOUT_GUIDE.png`: TL, TR, BL, BR, где 1 — верхняя поверхность, 0 — нижняя.

Для заборов открой вкладку **Terrains** слоя Fences и выбери тип **Забор и стена**. В наборе Match Sides хранятся все 16 комбинаций N/E/S/W.

## Размещение спрайтов

При первом открытии проекта включён плагин **Cozy Village & Farm Tools**. Он создаёт PackedScene для статичных PNG из Nature, Buildings, Props и Furniture и помещает их в `scenes/environment/`. Сцены не перезаписываются, если ты уже отредактировал их вручную. При добавлении новых спрайтов можно запустить меню **Project → Tools → Cozy Village & Farm: обновить сцены объектов** (название может отображаться в Tools в зависимости от локализации редактора).

Перетаскивай нужную сцену из FileSystem в соответствующую группу под `World/Objects`:
- `Nature` — деревья, кусты, цветы, камни и прочая природа;
- `Buildings` — здания и постройки;
- `Props` — предметы и уличный декор;
- `Interiors` — мебель.

У сцены спрайта точка установки привязана к нижнему центру текстуры; глубина отрисовки рассчитывается по Y-координате. Объект можно выбирать, перемещать, вращать, масштабировать, дублировать и удалять стандартными инструментами 2D-редактора. Эти сцены — декоративные спрайты; игровые ресурсные деревья и камни с логикой здоровья/добычи по-прежнему размещаются отдельными сценами из `scenes/objects/`.

## Pixel art

Слои TileMap и сцены спрайтов используют Nearest filtering. Для чистого пиксельного изображения не включай линейную фильтрацию и mipmaps для этих текстур.
