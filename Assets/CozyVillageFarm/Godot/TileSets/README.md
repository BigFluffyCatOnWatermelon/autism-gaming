# Cozy Village & Farm — TileSet и размещение объектов

## Основные слои карты

- **Ground** — сезонные покрытия, вода, глубокая вода и переходы.
- **Farming** — культуры и стадии роста.
- **Fences** — один общий набор заборов: деревянный, тёмный, белый и каменная стена.
- **Decorations** — растительность и мелкий декор.
- **AssetLibraries** — остальные библиотеки ассетов.

### Заборы

Выбирай один слой Terrain/Fences. В TileSet он содержит один Terrain «Забор (дерево, тёмный, белый, камень)» и четыре AtlasSource:
1. Деревянный.
2. Тёмный.
3. Белый.
4. Каменная стена.

У каждого атласа 16 вариантов (4×4) для всех соединений. Режим автосоединения — **Match Sides**. Все стили находятся в одном TileSet и одном TileMapLayer; четыре отдельных слоя больше не нужны. Внизу панели TileMap открой вкладку **Tiles** и выбирай нужный AtlasSource/стиль. Для соединения используй **Terrains → Connect**.

## Где брать объекты

После первого открытия проекта плагин создаёт сцены объектов в папке:

res://scenes/environment_assets/

Открой эту папку в панели **FileSystem** (обычно слева снизу, вкладка FileSystem). Внутри будут каталоги:

| Папка | Что внутри |
|---|---|
| Nature | Деревья, кусты, камни, цветы, растения |
| Buildings | Дома, сараи, магазины, теплица |
| Props | Бочки, сундуки, фонари, ворота и декор |
| Interiors/Furniture | Мебель |
| Animals | Животные |
| Characters | Персонажи и NPC |
| Beach_Fishing | Лодки, пляжные предметы и рыбалка |
| Effects | Эффекты |

Выбирай именно файлы **.tscn**, а не исходные PNG. Это подготовленные сцены со спрайтом, точкой установки и физикой там, где она нужна.

## Как поставить объект на карту

1. Открой scenes/world.tscn.
2. В дереве сцены разверни World → Objects.
3. Выбери группу: Nature для дерева, Buildings для дома, Props для бочки, Animals для животного и так далее.
4. В FileSystem раскрой scenes → environment_assets → Nature и выбери, например, Trees → spring → oak_spring.tscn.
5. Перетащи .tscn прямо в 2D-окно или на нужную группу в дереве сцены.
6. Выбери поставленный объект инструментом Select/Move (Q) и передвинь на нужное место. Корень сцены находится у основания спрайта, поэтому ориентируйся по нижней точке.

Для дома перетаскивай сцену из Buildings внутрь World/Objects/Buildings. Для животного — из Animals в World/Objects/Animals. Не добавляй исходные PNG напрямую, иначе у объекта не будет подготовленного корня и коллизии.

## Если папка environment_assets ещё пустая

Проверь, что плагин включён: Project → Project Settings → Plugins → Cozy Village & Farm Tools → Enable. Дождись завершения первого импорта ресурсов. Плагин создаёт .tscn локально в проекте; сгенерированные сцены не хранятся на GitHub и появляются при первом открытии Godot.

Для повторного сканирования новых PNG используй Project → Tools → Cozy Village & Farm: обновить каталоги и сцены. Уже созданные сцены не перезаписываются.

## Инструменты TileMap

Выбирай TileMapLayer и внизу панели TileMap используй Paint, Line, Rectangle, Bucket Fill, Select и Picker. Для автопереходов Ground — Terrains → Connect. Для заборов — слой Fences и Terrains → Connect.

## Коллизии

- Заборы и каменная стена: полигоны стоек и соединений на всех 16 вариантах каждого атласа.
- Деревья: коллайдер у основания ствола, крона не блокирует проход.
- Камни/руды: коллайдер нижней части.
- Здания: коллайдер фундамента.
- Кусты, некоторые пропсы, мебель и животные: коллизия опорной части.
- Вода/глубокая вода: блокирующие полигоны; угловые переходы блокируют только водную четверть.
- Цветы, трава, ковры, лёд и мосты остаются проходимыми.
