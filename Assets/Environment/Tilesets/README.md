# Набор тайлов ландшафта

Размер ячейки — **32×32 px**. Атлас `terrain_atlas.svg` содержит базовую траву и 47-тайловые blob-наборы для почвы, камня, песка, воды и дорожек. Наборы используют Terrain Mode **Match Corners and Sides**: Godot сам выбирает края, внешние и внутренние углы при рисовании.

`details.tres` подключает отдельный атлас мелких объектов: травы, цветов, камешков, грибов и кустиков.

Слои подключаются в `scenes/terrain.tscn`: `Ground`, `Soil`, `Stone`, `Sand`, `Water`, `Paths` и `Decorations`. Слои покрытий рисуются независимо: например, вода накладывается поверх травяной основы и получает песчаную кромку. Для каждого слоя можно открыть нижнюю панель TileMap и выбрать режим Terrain.


## Важно: не путать два режима рисования Godot 4.7

- **Scene Paint Mode** в верхней панели 2D-редактора (клавиша `B`) рисует экземпляры целых сцен. Он запрашивает Scene Picker и не предназначен для тайлов ландшафта.
- Для карты используй обычный **Select** (клавиша `Q`), выбери `TileMapLayer` в дереве сцены и работай в нижней панели **TileMap**. Там выбирай `Tiles` или `Terrains` и инструмент `Paint`.
