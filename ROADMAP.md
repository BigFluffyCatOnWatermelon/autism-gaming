# Дорожная карта Object Builder

## Принципы интерфейса

1. Сначала показывать только действия, нужные для текущего шага.
2. Категории, поиск и избранное — основной способ навигации по библиотеке.
3. Свойства группировать по смыслу; редко используемые параметры скрывать в «Дополнительно».
4. Не дублировать возможности штатного Inspector и Scene dock без необходимости: сначала интегрироваться со средствами Godot.
5. Любые изменения определения сохранять явно; опасные изменения показывать с предварительным просмотром.
6. Панели должны сворачиваться и менять ширину, длинные описания и предупреждения не должны раздувать основной экран.
7. Основные действия должны быть одинаковыми у объектов всех категорий.

## Навигация

- Библиотека — поиск, категории, теги, избранное, недавние объекты.
- Конструктор — основная сцена, дерево узлов и Inspector.
- Компоненты — каталог готовой логики и настройки.
- Шаблоны — заготовки и варианты объектов.
- Диагностика — ошибки, отсутствующие ресурсы, несовместимые компоненты и версии.

В 0.1.0 библиотека и простая форма редактирования находятся в одном компактном доке. Разделение на полноценные страницы вводится только тогда, когда добавится достаточно функций.

## Границы релизов

- 0.1.0 — основа: runtime API, пустые объекты, базовая библиотека, пользовательские свойства и копирование шаблонов.
- 0.2.0 — библиотека с категориями, поиском, избранным, недавними объектами и фильтрами тегов; базовое дерево сцены с добавлением/удалением узлов.
- 0.2.1 — редактирование определений пользовательских свойств, описания, групп, флага дополнительных параметров и числовых диапазонов.
- 0.2.2 — runtime API типизированных свойств, проверка значений, числовые ограничения и CI smoke-тесты.
- 0.3.0 — базовый визуальный редактор Sprite2D с предпросмотром текстуры и настройкой кадра/смещения/отражения.
- 0.3.1 — AnimatedSprite2D/SpriteFrames: выбор ресурса, анимации и кадра, предпросмотр и Speed Scale.
- 0.3.2 — настройка Loop Mode, visual origin/attachment points и collision editor.
- 0.4.0 — мастер типизированного создания объектов, параметры по типу и синхронизация Object Builder со штатным Inspector/Scene dock.
- 0.4.1 — Inspector-поля для пользовательских параметров и сохранение значений в сцене.
- 0.4.2 — каталог и UI компонентов Object Builder, типизированные настройки компонентов в штатном Inspector.
- 0.4.3 — Damageable: приём урона, множитель и плоское снижение с передачей результата в Health.
- 0.4.4 — изолированная тестовая сцена компонентов, ручные действия и отдельный CI smoke-тест.
- 0.4.5 — компонент Attack с проверкой дистанции/cooldown и интеграцией с Damageable.
- 0.5.0 — расширение набора игровых компонентов и интеграция с игровыми объектами.
- 0.6.0 — безопасная интеграция с текущими деревьями/камнями.
- 1.0.0 — стабильная схема, миграции, шаблоны и документация.

## Правило качества

Пункт можно отметить выполненным только после проверки кода и, где это важно, ручной проверки в Godot. Headless CI не заменяет проверку интерфейса, предпросмотра и поведения объектов в редакторе.
