# Инструкции для AI-ассистента

Перед работой обязательно прочитай:
- `README.md`
- `PROJECT_STATE.md`
- `TASKS.md`
- последние записи `CHANGELOG.md`

Затем изучи реальные файлы проекта. Документация может отставать от кода.

Правила:
- Репозиторий — источник истины; не полагайся на память другого чата.
- Сохраняй текущую архитектуру, не переписывай несвязанные части.
- Делай небольшие и проверяемые изменения.
- Не придумывай игровую концепцию за пользователя.
- Основной стек: Phaser 4 + JavaScript + Vite; запуск в StackBlitz.
- После каждой завершённой задачи обновляй PROJECT_STATE.md, TASKS.md и CHANGELOG.md.
- Честно сообщай, что проверено, а что нет.
- Не отмечай незавершённые задачи выполненными.
