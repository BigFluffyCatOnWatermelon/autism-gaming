# Инструкции для AI-ассистента

Перед работой прочитай README.md, PROJECT_STATE.md, TASKS.md и последние записи CHANGELOG.md. Затем изучи реальные исходники GitHub.

- Не полагайся на память предыдущего чата.
- Главные настраиваемые параметры находятся в src/config/gameConfig.js. Не дублируй их значения в UI или игровых системах.
- Используй модульную структуру src/game: сцены, сущности, системы, UI и утилиты.
- Не переписывай несвязанный рабочий код.
- Сохраняй игру запускаемой в браузере через StackBlitz; не требуй от пользователя локальной установки.
- Графические ресурсы первой версии создаются процедурно. Для внешних ресурсов проверяй лицензию и обновляй public/assets/LICENSES.md.
- После каждой завершённой задачи обновляй PROJECT_STATE.md, TASKS.md и CHANGELOG.md.
- Честно указывай, что фактически проверено. Не заявляй, что сборка или игровой тест прошли, если не запускал их.
- Сохраняй изменения логичными коммитами в GitHub.
