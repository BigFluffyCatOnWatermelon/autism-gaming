# Размещаемые объекты Cozy Village & Farm

Папки с готовыми сценами создаются плагином при первом открытии проекта:

- Nature — деревья, кусты, камни и растения.
- Buildings — здания.
- Props — предметы окружения и уличный декор.
- Interiors/Furniture — мебель.
- Animals — животные.
- Characters — NPC и персонажи.
- Beach_Fishing — пляж и рыбалка.
- Effects — эффекты.

Перетаскивай файлы .tscn в 2D-окно или на соответствующую группу под World/Objects в дереве сцены. Не перетаскивай исходные PNG: подготовленные сцены имеют корень, точку привязки по нижнему центру, сортировку и коллизию.

Пример полного пути к дереву:
scenes/environment_assets/Nature/Trees/spring/oak_spring.tscn

Если папок ещё нет, включи плагин Cozy Village & Farm Tools и дождись первого импорта. Для повторного сканирования используй Project → Tools → Cozy Village & Farm: обновить каталоги и сцены.
